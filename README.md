# 糖豆分拣机 · Rainbow Candy Sorter

把不同颜色的彩虹糖自动分拣到不同容器的桌面装置。

> 本目录是 `HardwareDesign2026` 仓库下的**独立子项目**，与仓库根目录的「智能桌宠」课程资料互不影响。

---

## 项目简介

糖豆从料斗经振动送料进入检测位 → 颜色传感器读取 RGB 并分类 → 旋转导流槽预先转到目标容器方向 → 释放挡板放行 → 糖豆落入对应容器。全程由 **ESP32 上的 FreeRTOS 以 4 个任务并发调度**。

| 指标 | 目标值 |
|---|---|
| 可分辨颜色 | 6 种（红 / 橙 / 黄 / 绿 / 蓝 / 紫）|
| 分拣速度 | 约 20–30 颗/分钟 |
| 判色准确率 | ≥ 95%（加遮光罩并标定后）|
| 硬件成本 | 基础版 ≈ ¥250 |

### 2. 烧录固件

需要 VS Code + [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) 插件。

```bash
cd firmware
pio run              # 编译
pio run -t upload    # 烧录
pio device monitor   # 串口监视 (115200)
```

依赖库由 PlatformIO 按 `platformio.ini` 自动安装，无需手动下载。

### 3. 标定颜色（必做）

默认色相区间是通用值，实际糖豆/光照必有偏移，**必须标定**：

```bash
c 0     # 把检测位上的红糖果标定为 RED
c 1     # 换成橙色，标定为 ORANGE
c 2 ... c 5
s       # 保存到 Flash (NVS, 掉电不丢)
p       # 打印状态与各色计数
r       # 清除标定，恢复默认区间
z       # 计数清零
```

## 硬件要点

| 组件 | 型号 | 接口 |
|---|---|---|
| 主控 | ESP32 DevKitC / NodeMCU-32S | — |
| 颜色传感器 | TCS34725 | I2C `0x29`，SDA=21 / SCL=22 |
| 到位检测 | TCRT5000 反射式红外 | `GPIO34` |
| 显示 | SSD1306 0.96" OLED | I2C `0x3C`，与传感器共用总线 |
| 执行 | MG996R ×1（导流槽）+ SG90 ×2（搅拌桨/释放挡板）| `GPIO13` / `GPIO14` / `GPIO4` |
| 送料 | 偏心振动马达 + MOSFET | `GPIO25` |
| 指示 | WS2812 + 蜂鸣器 | `GPIO32` / `GPIO26` |
| 供电 | **5V / 3A 独立电源** | 舵机不可从开发板取电 |

完整引脚表与接线图见 [docs/03_接线图与引脚分配.md](docs/03_接线图与引脚分配.md)。

## 软件架构一览

| 任务 | 优先级 | 核心 | 职责 |
|---|---:|---:|---|
| `TaskSorter` | 3 | Core 1 | 舵机时序、计数（实时性最高）|
| `TaskColor` | 2 | Core 0 | 采样 → 中值滤波 → 判色 → 入队 |
| `TaskFeeder` | 2 | Core 1 | 振动送料、防架桥、到位检测 |
| `TaskUI` | 1 | Core 0 | OLED 刷新、串口命令 |

同步原语：`semCandyPresent`（送料→判色）、`semCycleDone`（分拣→送料，节拍闸门）、`queueColor`（判色→分拣）、`i2cMutex`（TCS34725 与 OLED 共用 I2C）、`countMutex`（计数保护）。

详见 [docs/01_系统架构与技术栈.md](docs/01_系统架构与技术栈.md)。
