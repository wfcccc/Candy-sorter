# 三舵机糖豆分色器 v3 · Candy Sorter v3

用颜色给每颗糖豆找到它自己的盒子。

> **本版按效果图全面重做**：结构从 3D 打印改成 **5 mm 泡棉板手工切割**，传感器从 TCS34725 换成 **AS7341 11 通道光谱**，检测仓缩到「糖豆 + 2 mm」见方，底部改成**摇臂 + 三角垫块 + 斜导流槽**。
> 不需要 3D 打印机，不需要建模，买齐材料当天就能下刀。

---

## 项目简介

```
糖豆盒 → 重力单列导管 → 挡板A(上) → [单颗测色仓] → 挡板B(下)
                                    ↑ A 和 B 之间就是检测仓
                                       B 同时充当仓底板与放料门
         → 固定落料管 → 摇臂上的斜导流槽 → 5 个方盒 + 1 个废料槽
```

糖豆靠重力进入内径「糖豆直径 + 2 mm」的单列导管（**内径小于两倍糖豆直径，两颗并排在几何上不可能**）。挡板A / 挡板B 一开一合把队列分离出一颗：A 抽开时整列下滑、最下一颗落到 B 上；A 关闭时刀刃正好楔进两颗糖豆的切点，把上面的整列闸住。

这一颗被 A 和 B 夹在**只有「糖豆 + 2 mm」见方**的黑色仓腔里，TCRT5000 确认到位，AS7341 透过遮光罩上的窗口读取 8 个窄带可见光通道判色。底部 SG90 把摇臂上的斜导流槽转到目标盒位，挡板B 抽开，糖豆笔直穿过落料管落到导流槽的**高端**（高端就在摇臂轴心上，所以**无论转到哪个角度都必定接得住**），再靠重力滚进对应盒子。

全程由 **ESP32 上的 FreeRTOS 以 4 个任务并发调度**。

| 指标 | 目标值 |
|---|---|
| 可分辨颜色 | 5 种（红 / 橙 / 黄 / 绿 / 蓝）|
| 分拣速度 | 25–33 颗/分钟（理论节拍 1.70 s）|
| 判色准确率 | ≥ 95%（遮光并标定后）|
| 卡料率 | ≤ 2 次 / 100 颗 |
| 硬件成本 | 基础版 ≈ ¥250，**不需要 3D 打印机** |
| 舵机 | SG90 ×3（底部推荐换 MG90S）|

## 与上一版的区别

| 环节 | 上一版 | **本版** |
|---|---|---|
| 结构材料 | 3D 打印 PLA + 亚克力 | **5 mm 泡棉板 / 双层瓦楞板** |
| 加工方式 | 建模 → 切片 → 打印数小时 | **美工刀 + 钢尺，当天完成** |
| 骨架 | 底座 + 立柱 | **L 形骨架**：底板 + 背板 + 上层板 |
| 颜色传感器 | TCS34725（3 个宽带通道）| **AS7341（8 个窄带 + Clear + NIR）** |
| 判色算法 | HSV 色相区间 | **归一化光谱向量的最近邻** |
| 检测仓 | 44×46×58 mm 大黑盒 | **A 和 B 之间**，只有「糖豆+2 mm」见方 |
| 底部机构 | 轴心汤匙 + 短导槽 | **摇臂 + 三角垫块 + 斜导流槽 15°** |
| 容器 | 圆杯 ×6 | **方盒 60×60×60 ×5 + 废料槽** |
| 外接照明 | 2 颗白光 LED + S8050 驱动 | **不需要**（AS7341 模块自带 LED）|

> **从上一版改装只需动两处**：① 把 TCS34725 换成 AS7341（**接线位置完全一样**，地址从 0x29 变 0x39，一根线都不用动）；② 舵机引脚 GPIO13/14/4 含义完全不变。

### 2. 烧录固件

需要 VS Code + [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) 插件。

```bash
cd firmware
pio run              # 编译
pio run -t upload    # 烧录
pio device monitor   # 串口监视 (115200)
```

依赖库由 PlatformIO 按 `platformio.ini` 自动安装，无需手动下载。

### 3. 先用「手动调试模式」把机械调好（强烈建议）

装配阶段不用改代码、不用反复烧录，直接用串口命令逐个动作：

```bash
m          # 进手动模式 + 自动演示一次完整动作
a 1 / a 0  # 单独开/关 挡板A
b 1 / b 0  # 单独开/关 挡板B
d 90       # 单独把底部摇臂转到 90°
x          # 退出手动模式，恢复自动分拣
```

### 4. 调光 → 封光 → 标定（必做，顺序不能反）

```bash
t       # 开原始光谱流：先关灯看 CLR 有没有掉下来（有 = 遮光罩漏光，先返工）
        # 再用它核对 MIN_CLEAR_LEVEL（详见 05 文档 §7.1）
c 0     # 把仓里的红糖果标定为 RED —— 存下这条归一化光谱
c 1     # 换成橙色，标定为 ORANGE
c 2 ... c 4
s       # 保存到 Flash (NVS, 掉电不丢)
p       # 打印状态、计数、以及 5 条参考光谱（用来肉眼比对曲线形状）
r       # 清除标定，回到默认色相区间兜底模式
z       # 计数清零
u       # 暂停 / 继续
h       # 完整命令列表
```

## 硬件要点

| 组件 | 型号 | 接口 |
|---|---|---|
| 主控 | ESP32 DevKitC / NodeMCU-32S | — |
| 光谱传感器 | **AS7341**（带板载白光 LED）| I2C `0x39`，SDA=21 / SCL=22 |
| 到位检测 | TCRT5000 反射式红外 | `GPIO34`（右壁，距糖豆 5–6 mm）**+ 10 kΩ 上拉** |
| 显示 | SSD1306 0.96" OLED | I2C `0x3C`，与传感器共用总线 |
| 执行 | **SG90 ×3** | 挡板A=`GPIO13` / 挡板B=`GPIO14` / 底部摇臂=`GPIO4` |
| 指示 | WS2812 + 蜂鸣器 + 按键 | `GPIO32` / `GPIO26` / `GPIO27` |
| 预留 | 外接照明 LED / 防架桥振动马达 | `GPIO33` / `GPIO25`（默认都不用）|
| 结构 | **5 mm 泡棉板 / 双层瓦楞板** | 美工刀 + 钢尺 + 热熔胶 |
| 供电 | **5V / 3A 独立电源** | 舵机不可从开发板取电 |

完整引脚表与接线图见 [docs/03_接线图与引脚分配.md](docs/03_接线图与引脚分配.md)。

## 软件架构一览

| 任务 | 优先级 | 核心 | 拥有的硬件 | 职责 |
|---|---:|---:|---|---|
| `TaskGate` | 4 | Core 1 | 挡板A | 闸门时序、TCRT5000 到位确认、重试与卡料判定 |
| `TaskSorter` | 3 | Core 1 | 挡板B + 底部摇臂 | 转盒位、放料、**反向确认放走**、计数、归还节拍 |
| `TaskColor` | 3 | Core 0 | AS7341 | 读光谱 → 中值滤波 → 归一化最近邻 → 入队 |
| `TaskUI` | 1 | Core 0 | OLED/灯带/按键/串口 | 显示、人机命令、手动调试模式 |

同步原语：`semCandyOnB`（闸门→判色）、`queueColor`（判色→放料）、`semNextCandy`（放料→闸门，**节拍闸门**）、`i2cMutex`（AS7341 与 OLED 共用 I2C）、`countMutex`（计数保护）。

**每个舵机只由一个任务拥有**，所以不存在两个任务抢同一个舵机的问题；手动调试模式靠 `g_manualMode` 让机械任务主动让出舵机。

详见 [docs/01_系统架构与技术栈.md](docs/01_系统架构与技术栈.md)。

## 调参入口

所有引脚、舵机角度、时序、判色阈值都集中在 `firmware/include/config.h`，**改参数不需要动 `main.cpp` 的逻辑**。

最常改的几项：

| 参数 | 位置 | 用途 |
|---|---|---|
| `CANDY_DIAMETER_MM` / `CANDY_THICKNESS_MM` | config.h §3 | 糖豆实测尺寸；下面三个仓腔尺寸由它自动推出 |
| `kBinAngle[]` | config.h §3 | 5 个盒位角度（默认 `{30, 170, 65, 100, 135}`，按图摆放）|
| `SORTER_TRIM_DEG` | config.h §3 | 底部摇臂整体偏移微调 |
| `AS7341_ATIME` / `AS7341_ASTEP` | config.h §4 | 积分时间（TINT = (ATIME+1)×(ASTEP+1)×2.78µs）|
| `AS7341_GAIN` / `AS7341_LED_MA` | config.h §4 | 增益与照明亮度，判色灵敏度与高光的取舍 |
| `MIN_CLEAR_LEVEL` | config.h §4 | "仓里有没有糖豆"的亮度门限，换档位后必改 |
| `MAX_SPECTRAL_DIST` | config.h §4 | 光谱最近邻的接受阈值；调大更宽容，调小更严格 |
| `GATE_OPEN_ANGLE` | config.h §5 | 闸板开度（默认 65°，不够就加到 70–75）|
| `T_GATE_MOVE` / `T_SORTER_MOVE` / `T_DROP_HOLD` | config.h §6 | 节拍时序，是提速的主要旋钮 |
| `USE_EXTERNAL_LED` | config.h §1 | 只有用「没有板载 LED 的 AS7341 模块」时才改成 `1` |
| `ENABLE_VIB_UPGRADE` | config.h §9 | 改成 `1` 打开可选防架桥振动马达 |
