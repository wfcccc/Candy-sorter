# 三舵机糖豆分色器 · 硬件采购清单（BOM v3）

> 链路：ESP32 → 重力送料 → 挡板A / 挡板B 双闸门单颗分离 → 黑色遮光检测仓（AS7341 判色）→ 底部 SG90 摇臂斜导流槽分流进 5 个方盒
> 结构方案：**5 mm 泡棉板 / 双层瓦楞板手工切割**（本版取消 3D 打印）｜感知方案：**AS7341 11 通道光谱**
> 价格口径：2024–2025 年国内电商散买参考价；小计按价格区间下限计，五金散件包邮差异大，±15% 属正常

## 0. 本版变化速览（v2 → v3）

- 结构件：3D 打印 PLA → **5 mm 泡棉板 / 双层瓦楞板手工切割**（美工刀 + 钢尺 + 热熔胶）。
- 传感器：TCS34725 → **AS7341 11 通道光谱模块**（自带板载白光 LED，省掉外接 LED + 三极管 + 限流电阻）。
- 删除项：PLA、代打费、亚克力管 / 板、MG996R 大舵机。
- 结果：总价基本持平，但**不用等打印、不用建模，当天可下刀装机**。

## 4. 关键元件选购要点（避坑）

| 元件 | 选购要点 | 踩坑后果 |
| --- | --- | --- |
| **AS7341 模块（最关键）** | 必须选**带板载白光 LED** 的版本；认准 I2C 地址 0x39；有些模块把 LED 直接接 VCC 常亮，那种也行，但就没法用固件的 enableLED() 控制 | 不带 LED 就要自己补 LED + 限流电阻，白平衡极难做 |
| **单列导管** | 内径必须**大于糖豆直径、且小于两倍糖豆直径**：球形 φ13 → 内径 φ15；扁圆形（M&M 型，直径 13 厚 5）→ 内径 φ15 也行。买之前用游标卡尺量 | 内径 ≤ 糖豆直径会卡豆，≥ 2 倍直径会两颗并排下落 |
| **泡棉板** | 选 5 mm 厚、表面有纸面 / 卡纸面的（也叫雪弗板、KT 板、PVC 发泡板）；双层瓦楞板更硬更便宜，但切面粗糙、容易掉屑 | 太软的珍珠棉一压就变形，导轨和闸门全部失准 |
| **黑色绒布 / 卡纸** | 必须是**哑光黑** | 亮面黑会反光，等于没遮光，判色直接崩 |
| **ESP32 开发板** | CP2102 或 CH9102 串口芯片 | 杂牌 CH340 偶发识别不稳、下载失败 |
| **TCRT5000** | 要数字输出 DO，板上带 LM393 + 可调电位器 | 只有 AO 模拟输出的版本阈值全靠 ADC，抖动大 |
| **SG90 / MG90S** | 仿品扭矩虚标严重，3 个尽量同批次买 | 力道不一致，闸门开合时间对不齐 |
| **电源** | 3 个 SG90 峰值约 2.1 A，选 5 V/3 A，并 1000 µF 电容 | 供电不足会复位、舵机抖动、ESP32 重启 |
| **热熔胶** | 胶枪温度别太高（泡棉板会烫穿），打胶要快 | 高温把泡棉板烫塌，结构件直接报废 |

## 6. 采购顺序与省钱提示

1. 先买**糖豆 + 游标卡尺**：量出真实直径，再定导管内径和收纳盒尺寸。
2. 再买 **AS7341 + ESP32**：先点亮 OLED、读通 11 通道，判色算法通了再动结构。
3. 结构材料最后买：泡棉板、热熔胶、单列导管，尺寸确定后一次买齐。
4. 舵机、电源、1000 µF 电容一次买齐：供电是这台机器最容易翻车的地方。
5. 省钱点：ESP32、5 V/3 A 电源、热熔胶枪、美工刀 / 钢尺 / 切割垫若已有，整机可压到 **≈ ¥150**。
6. 先做**单颗分离**（挡板A/B + TCRT5000），再做**判色**（AS7341），最后做**分流入盒**（底部舵机 + 导流槽），每步跑通再往下。
7. 泡棉板会吸水变形，装好后避免放在潮湿处；关键受力面用两层泡棉板对贴加厚。

## 7. 上电验收清单（买齐后按顺序做）

1. 只接 ESP32 + OLED + AS7341：I2C 扫到 0x39 与 0x3C，读数正常。
2. 接 5 V/3 A 电源（不接舵机）：量到 5.0 V 以上，接上 1000 µF 后更稳。
3. 逐个接舵机并手动给角度：三个都不抖、不重启，再装挡板。
4. 关灯测试测色仓：OLED 上环境光读数接近 0，否则继续加黑色内衬补漏光。
5. 全部装好后连续跑 50 颗：统计卡豆次数与错分次数，再决定要不要加进阶项。
