# 05 · 装配与调试指南

> 面向第一次上手的人，按顺序做完即可让机器跑起来。
> 预计工时：**6–10 小时**（含 3D 打印等待时间）。

---

## 0. 总体流程

```text
① 采购 → ② 打印结构件 → ③ 焊驱动板 → ④ 装配机械 → ⑤ 接线
   → ⑥ 烧录固件 → ⑦ 通电自检 → ⑧ 标定颜色 → ⑨ 调参跑顺 → ⑩ 统计验收
```

**强烈建议**：不要一次装完再通电。**分阶段验证**能让你少走 80% 的弯路。

---

## 1. 阶段一：最小系统点亮（约 30 min）

**目标**：证明 ESP32、I2C、OLED、传感器都活着。

1. 只接：ESP32 + OLED + TCS34725 + 电源。
2. 烧录一个 I2C Scanner 草图，确认能看到：
   ```
   I2C device found at 0x29   ← TCS34725
   I2C device found at 0x3C   ← OLED
   ```
3. 烧录本项目固件，观察串口是否打印 `TCS34725 OK`。
4. 观察 OLED 是否显示标题。

**✅ 通过标准**：两个 I2C 地址都能扫到，串口无 `not found`，OLED 有显示。

**❌ 不通就查**：SDA/SCL 是否接反、是否共地、模块是否 3.3 V 供电。

---

## 2. 阶段二：驱动电路焊接（约 45 min）

1. 按 `03_接线图与引脚分配.md` 第 4 节焊 MOSFET 驱动电路。
2. 先**不接马达**，用万用表测 GPIO25 为高时，MOSFET 漏-源是否导通。
3. 接上振动马达，串口发一个简单测试（或临时把 GPIO25 拉高 1 秒），确认马达转。

**✅ 通过标准**：GPIO25 高 → 马达转；GPIO25 低 → 马达停；MOSFET 不烫。

**❌ 不通就查**：是否用了非逻辑电平 MOSFET（如 IRF540）、栅极是否串了 100 Ω、二极管方向是否反了。

---

## 3. 阶段三：机械装配（约 2–3 h）

按以下顺序装配，**每步都手动试转一下**：

| 步骤 | 内容 | 检查点 |
|---:|---|---|
| 1 | 底座 + 立柱 | 立柱垂直不晃 |
| 2 | 检测台 + 遮光罩 | 遮光罩扣上后**看不到内部亮光** |
| 3 | 装 TCS34725 到遮光罩 | 传感器镜头朝下，距停位 12–15 mm |
| 4 | 装 TCRT5000 | 对准停位，距糖豆 ≈ 5 mm |
| 5 | 装释放挡板 + SG90 | 手动转舵机，挡板能完全挡住/放行 |
| 6 | 装料斗 + 搅拌桨 + SG90 | 搅拌桨转动不碰壁 |
| 7 | 装振动马达到料斗外侧 | 用热熔胶固定，马达不松 |
| 8 | 装滑道（15°）| 放一颗糖豆，能顺畅滚到停位 |
| 9 | 装导流槽 + MG996R | 上电前手动转到 0°/150°，无干涉 |
| 10 | 装容器托架 + 6 个容器 | 每个容器正对导流槽对应角度 |

**✅ 通过标准**：手动放糖豆能滚到停位并停稳；导流槽在 0–150° 全程无卡碰；容器落点对准。

**❌ 常见问题**：
- 糖豆停在滑道中间 → 加大倾角或打磨内壁
- 糖豆在料斗架桥不下料 → 搅拌桨角度不对，或出料口太大
- 导流槽刮容器 → 调整容器半径或导流槽弧长

## 4. 阶段四：全线上电与烧录

### 4.1 烧录步骤

```bash
# 方式一：PlatformIO（推荐）
# VS Code 打开 firmware/ 目录 → 点击左下角 ✓ (Build) → → (Upload) → 插头图标 (Monitor)

# 方式二：命令行
cd firmware

pio run -t upload    # 烧录
pio device monitor   # 串口监视 (115200)
```

### 4.2 上电自检

对照 `03_接线图与引脚分配.md` 第 8 节的 10 步自检表逐项确认。

**上电瞬间应该看到**：
- 板载 LED 常亮
- 导流槽舵机转到中位（90°）
- 释放挡板关闭
- OLED 显示 `CANDY SORTER` + 6 行计数
- 串口打印完整启动日志
- 蜂鸣器「嘀」一声

## 5. 阶段五：颜色标定（关键步骤）

出厂默认的色相区间是**通用值**，实际糖豆/光照不同必有偏移，**必须标定**。

### 5.1 标定流程

1. 从包装里挑出 6 颗**颜色最标准**的糖豆（红、橙、黄、绿、蓝、紫各一颗）。
2. 用手（或让机器送料）把红的那颗放到检测位。
3. 打开串口监视器，输入：
   ```
   c 0
   ```
   应返回：
   ```
   CAL RED: hue=358.2 sat=0.71 (R1240 G310 B290 C2100)
   send 's' to save to flash
   ```
4. 换橙色糖豆到检测位，输入 `c 1`；依次到 `c 5`。
5. 全部完成后输入 `s` 保存到 Flash。

### 5.2 标定结果自检

输入 `p`，检查 6 个色相值是否**彼此分离**：

```
state=1 total=0 unknown=0 jam=0 calibrated=1
  RED     0
  ORANGE  0
  YELLOW  0
  GREEN   0
  BLUE    0
  PURPLE  0
```

再逐颗放糖豆，观察串口判色是否正确。

### 5.3 判色不准怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 总是 UNKNOWN | 亮度不足 | 让 TCS34725 补光 LED 常亮；检查 `MIN_CLEAR_LEVEL` 是否过高 |
| 总是 UNKNOWN | 饱和度门限过高 | 把 `config.h` 的 `MIN_SATURATION` 从 0.28 降到 0.20 |
| 红/橙不分 | 色相太接近 | 加大采样次数 `COLOR_SAMPLE_TIMES`；或接受合并为一种 |
| 黄/绿不分 | 同上 | 用摄像头方案（OpenMV）替代 |
| 同一颗糖忽红忽橙 | 反光导致采样不稳 | 加遮光罩、打磨糖豆下方凹槽、增大采样次数 |
| 换一批糖豆就全乱 | 批次色差 | **重新标定** |

> **加重判据技巧**：除色相外，可加入**亮度比**辅助。例如黄色糖豆的 Green 通道绝对强度通常明显高于橙色。若你有此需求，在 `classifyColor()` 里加二次判据即可。

## 6. 阶段六：节拍与动作调参

所有参数都在 `firmware/include/config.h`，改完重新编译烧录即可。

### 6.1 常见调参场景

| 症状 | 调整参数 | 方向 |
|---|---|---|
| 糖豆还没停稳就读色，判色乱 | `T_SETTLE_AFTER_FEED`、`T_COLOR_SETTLE` | **调大**（各 +100 ms）|
| 导流槽还没转到位糖豆就掉了 | `T_DIVERTER_MOVE` | **调大**（+100~200 ms）|
| 糖豆卡在挡板上没落下 | `T_RELEASE_HOLD`、`RELEASE_OPEN_ANGLE` | 时间调大 / 角度调大 |
| 挡板回位太慢，下一颗撞上 | `T_RELEASE_RECOVER` | 调大 |
| 整机太慢（想更快）| 上述 4 个参数 | 逐项**调小**，每次 50 ms，直到临界再加 20 ms 余量 |
| 送料老是超时报警 | `T_VIB_TIMEOUT`、`T_VIB_ON`/`T_VIB_OFF` | 超时调大；振动脉宽调长 |
| 一次掉两颗糖豆 | 出料口太大 / `T_VIB_ON` 太长 | 缩小出料口；减小振动脉宽 |
| 导流槽落点偏一点 | `kBinAngle[]` | 微调对应角度 ±3° |

### 6.2 推荐调参顺序

```text
1. 先调「送料」   → 保证每次只出一颗、且能到停位
2. 再调「判色」   → 保证停稳后读数稳定
3. 再调「导流槽」 → 保证转到位再放料
4. 最后压时间     → 逐项减小延时，逼近临界
```

**别跳步**。一次只改一个参数，改完记一笔（建议用下节的记录表）。

## 8. 验收测试

### 8.1 准确率测试

1. 随机取 **100 颗**混合糖豆放入料斗。
2. 跑完全程，记录每种颜色的**实际数量**（人工数）与**机器计数**（`p` 命令）。
3. 计算准确率：

```text
准确率 = (总计数 - 未知计数) / 总计数 × 100%
```

**✅ 验收标准**：
- 准确率 ≥ 95%
- 卡料次数 ≤ 2 次 / 100 颗
- 无漏分（无糖豆留在滑道或掉到地上）

### 8.2 速度测试

```text
分拣速度 = 100 颗 / 总耗时（分钟）
```

**✅ 验收标准**：≥ 20 颗/分钟（即 100 颗 ≤ 5 分钟）。

### 8.3 连续运行测试

连续跑 30 分钟，观察：
- 是否过热（MOSFET、舵机、电源）
- 计数是否有漂移
- 是否出现 I2C 死锁（表现为 OLED 卡住 + 不再分拣）

## 9. 故障速查总表

| 症状 | 排查顺序 |
|---|---|
| 上电无反应 | 电源 → 开关 → ESP32 板载 LED → USB 供电 |
| 串口无输出 | 波特率是否 115200 → 换 USB 数据线 → 换串口芯片驱动 |
| 扫不到 0x29 | SDA/SCL 接反 → 模块 VCC → 换模块 |
| OLED 花屏 | I2C 速度 → 上拉电阻 → 换 0x3D 地址 |
| 舵机不动 | 信号线 GPIO → 独立 5V 供电 → 舵机本身好坏（拿另一个试）|
| 舵机抖动/复位 | 电源电流不足 → 加 1000 µF 电容 → 增大电源功率 |
| 振动马达不转 | MOSFET 类型 → 栅极电压 → 马达本身 |
| 红外常触发 | 调电位器 → 加遮光 → 换 TCRT5000 |
| 判色全 UNKNOWN | 补光 LED → 遮光罩 → `MIN_CLEAR_LEVEL` / `MIN_SATURATION` |
| 卡料 | 出料口尺寸 → 搅拌桨 → 滑道倾角 → 打磨内壁 |
| 一次掉两颗 | 出料口过大 → 减小 `T_VIB_ON` → 加挡料毛刷 |
| 整机停摆不动 | 是否打印 JAM → 复位重启 → 检查 `semCycleDone` 是否被吞（重启恢复）|

## 10. 进阶优化建议

跑通基础版后，按收益排序可以考虑：

| 优化 | 收益 | 难度 |
|---|---|---|
| 加长滑道 + 二次检测位 | 判色更稳 | ★ |
| 滑道贴 PTFE 胶带 | 减少卡料 | ★ |
| 换成品振动盘 | 送料几乎不卡 | ★★ |
| 步进电机替换舵机做导流 | 定位精度提升 | ★★ |
| 加 ESP32 Web 页面 | 手机看统计 | ★★ |
| 加摄像头（OpenMV）| 判色准确率到 99% | ★★★ |
| 加自动分拣排序（按容器容量轮转）| 无需人工换杯 | ★★★ |
| 加称重模块（HX711）| 统计每色重量 | ★★ |

## 11. 安全与保养

- **断电再接插拔舵机**，带电插拔容易烧驱动。
- 长期不用时取出糖豆，避免受潮粘在滑道上。
- 每运行 10 小时，清理一次滑道与料斗内壁的糖粉。
- 3D 打印件不建议长期接触食品，可在接触面贴食品级 PTFE 胶带。
- 电源适配器要留散热空间，不要闷在密闭盒里。
