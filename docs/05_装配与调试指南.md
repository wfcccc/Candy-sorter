# 05 · 装配与调试指南（v3）

> 面向第一次上手的人，按顺序做完即可让机器跑起来。
> 预计工时：**6–9 小时**（不需要等 3D 打印）。

---

## 0. 总体流程

```text
① 采购 → ② 切泡棉板 → ③ 电路联调（不装机械）→ ④ 装遮光罩与双闸门
   → ⑤ 闸门标定 → ⑥ 装底部摇臂与斜导流槽 → ⑦ 盒位标定
   → ⑧ 装糖豆盒与单列导管 → ⑨ 调光与颜色标定 → ⑩ 调参跑顺 → ⑪ 统计验收
```

**强烈建议**：不要一次装完再通电。**分阶段验证**能让你少走 80% 的弯路。

**本指南最大的帮手是固件的「手动调试模式」**：

```bash
m          # 进入手动模式，并自动演示一次完整动作
a 1 / a 0  # 单独开/关 挡板A
b 1 / b 0  # 单独开/关 挡板B
d 90       # 单独把底部摇臂转到 90°
t          # 开关原始光谱数据流（调光、标定必用）
x          # 退出手动模式，恢复自动分拣
```

机械装配阶段 90% 的时间都在"动一下看看"，有了这组命令，**不用反复改代码烧录**。

---

## 1. 阶段一：最小系统点亮（约 30 min）

**目标**：证明 ESP32、I2C、OLED、AS7341 都活着。

1. 只接：ESP32 + OLED + AS7341 + 电源（**不接任何舵机**）。
2. 烧录一个 I2C Scanner 草图，确认能看到：
   ```
   I2C device found at 0x39   ← AS7341
   I2C device found at 0x3C   ← OLED
   ```
   > 如果只扫到 `0x3C`，先查 AS7341 的 `VIN` 是不是误接到了 5V —— 它只能用 3.3V。
3. 烧录本项目固件，观察串口：
   ```
   TCRT5000 idle level OK (HIGH)     ← 还没接 TCRT 时会报 WARN, 先忽略
   AS7341 OK  TINT=33 ms  LED=20 mA
   ```
4. 观察 AS7341 模块上的白光 LED 是否点亮。
5. 串口发 `t`，应开始每 300 ms 打印一行 8 通道数据：
   ```
   RAW F1..F8   120   118   115   110   108   105   102   100 | CLR   340 NIR   210 | hue= 210.0 sat=0.06 | (empty)
   ```

**✅ 通过标准**：两个 I2C 地址都能扫到，串口无 `not found`，OLED 有显示，LED 亮，`t` 有数据。

**❌ 不通就查**：SDA/SCL 是否接反、是否共地、模块是否 3.3 V 供电、模块型号是否带板载 LED。

---

## 2. 阶段二：电路联调（不装机械，约 40 min）

**这一步不要装任何机械件** —— 舵机空转最容易发现问题。

1. 把 3 个 SG90 只接信号线 + 独立 5 V 电源，**舵盘先不装**。
2. 烧录固件，打开串口逐个试：
   ```
   m            → 进手动模式，底部摇臂应扫过 0→180→0
   a 1 / a 0    → 1 号舵机（挡板A）应转 65° / 回 0°
   b 1 / b 0    → 2 号舵机（挡板B）应转 65° / 回 0°
   d 0 / d 90 / d 170  → 底部摇臂应分别转到三个角度
   ```
3. 接上 TCRT5000，串口发 `t`，用手挡在探头前再移开：
   - 手动模式下 OLED **不会**显示到位状态变化（到位检测只在自动循环里用）；
   - 用 `p` 命令看不到红外状态，所以这步靠**板上的指示灯**和后面的自动运行验证。

**✅ 通过标准**：
- 3 个舵机都能被**分别**控制，编号对得上（**这一步最容易接错，务必逐个确认**）；
- 舵机转动干脆、无抖动、无"吱吱"卡死声；
- ESP32 不复位。

**❌ 不通就查**：

| 现象 | 原因 |
|---|---|
| 某个命令动的是别的舵机 | 信号线接错了 GPIO，对照 `03` 文档 §1.1 |
| 舵机抖动 / ESP32 复位 | 舵机从开发板取电了，改独立 5 V + 1000 µF |
| 舵机只"吱吱"响不转 | 已经顶到机械限位（舵盘装歪了），或舵机本身坏了 |
| 命令发下去没反应 | 串口有没有回显？口令要按回车结尾；先发 `h` 看帮助 |
| 上电就打印 `FAULT` | 自检没过；看串口具体是 TCRT 还是 AS7341 那一行 |

## 3. 阶段三：切泡棉板（约 2 h）

按 `04` 文档 §4 的**切割清单**下料。要点：

| 要点 | 说明 |
|---|---|
| 刀要新 | 泡棉板是「切」不是「划」，刀片一钝就撕出毛边。切 20–30 刀换一次刀尖 |
| 用钢尺压住 | 每一刀都靠钢尺。手切的直边全靠它 |
| 分层切 | 5 mm 板分 2–3 刀切透，一刀到底容易斜 |
| 切完修边 | 400 目砂纸磨平切面，**尤其是导轨和闸板经过的地方** |
| 打孔 | 泡棉板不适合钻孔（会撕）。用**烧热的铁钉/竹签**烫孔 |
| ★ 配合件 | P8 摇臂、P9 三角垫块、P16 仓腔限位条 是配合件，公差要求高，切完必须试配 |

**✅ 通过标准**：所有零件尺寸对得上 `04` 文档 §4 的表；P16 四条限位条能正好围出一个 15 mm 见方的通道。

---

## 4. 阶段四：遮光罩 + 双闸门（约 2 h）

### 4.1 装遮光罩

按 `04` 文档 §5.1：

1. 5 块板（P12 左右、P13 前后、P14 顶、P15 底）用热熔胶粘成方筒；
2. **内壁贴黑色绒布**（哑光黑是硬要求）；
3. 前板开 φ12 观察窗，对准仓腔中心；
4. 顶板烫 φ16 过料孔 + 1.8 mm 挡板A 缝；底板烫 1.8 mm 挡板B 缝 + φ16 落料孔；
5. 闸板缝的**外侧**加一块小黑板做挡光檐；
6. 用 P16 四条限位条在筒内围出 15 mm 见方的通道。

**✅ 通过标准**：扣上后**从外面任何角度看都看不到内部亮光**。

### 4.2 装双闸门（关键步骤，约 40 min）

**这一步做不对，后面全白搭**（会出现一次掉两颗、或者夹碎糖豆）。

**装舵盘（按角度装，不要凭手感）**

```
串口发 m       → 进手动模式
串口发 a 0     → 舵机停在"全闭"位置（0°）
```

**在这时**把舵盘压到舵机轴上，让**摇臂指向背离遮光罩的方向**。
再发 `a 1`，摇臂应向前摆 65°，把闸板推出去。

**调闸板行程**

- 发 `a 1`（全开）时，闸板前缘必须**完全退出通道**；
- 发 `a 0`（全闭）时，闸板前缘必须**完全越过通道**。

不够就调 `GATE_OPEN_ANGLE`（默认 65，可加到 70–75），或者把摇臂上的销孔从 20 mm 挪到 22 mm。

**调 A/B 平面间距（最重要）**

在单列导管里放 **5 颗**糖豆，反复执行 `a 1 → a 0`，观察：

| 现象 | 原因 | 处理 |
|---|---|---|
| **一次掉下两颗** | A/B 间距**太大**，两颗都掉到 B 上 | 把挡板A 的机构往下移 1–2 mm（间距 15 → 13 mm）|
| **挡板A 关不上 / 夹住糖豆 / 舵机"吱吱"叫** | A/B 间距**太小**，刀刃切在糖豆身上而不是切点上 | 把挡板A 往上移 1–2 mm（间距 15 → 17 mm）|
| 有时一颗有时两颗 | 间距正好在临界值 | 往下移 1 mm 试试（宁可小一点，夹住的危害比多掉一颗小）|

> **原理**：A/B 净间距 = 糖豆直径 + 2 mm 时（图注值），A 抽开后最下一颗落到 B 上，第二颗正好停在 A 的平面上；A 关闭时刀刃楔进这两颗糖豆的**切点**，把整列闸住。间距必须 **大于 1 颗、小于 2 颗**。
>
> 用你自己的糖豆实测：**A—B 净高 = 糖豆直径 + 2 mm**。d=13 时就是 15 mm。

**失效安全**：挡住挡板B 的舵机断电，用手推闸板 —— 应该能推动。这是**故意的设计**（见 `04` 文档 §5.2）：断电时糖豆会一路滑到导流槽落进最近的盒子，而不是把整列卡死。

## 5. 阶段五：底部摇臂 + 斜导流槽（约 1.5 h）

### 5.1 装舵机台盒

1. 舵机放进 90×90 盒里，法兰用 M3 螺丝 + **扎带**固定在顶板上，轴朝上并伸出 φ25 孔；
2. 盒子粘到底板上，位置要让**舵机轴心正对遮光罩底板落料孔的正下方**（这是整机最重要的一条铅垂线）。

### 5.2 装摇臂与导流槽

1. 串口发 `d 0`；
2. 把 P8 摇臂压到舵盘上，让摇臂**指向 0° 基准线**（底板前端画的那条线）；
3. 把 P9 三角垫块（高 19 mm）粘在摇臂的轴心端；
4. 把 P10 底板 + P11 两条侧挡边粘成 U 形槽（内宽 20 mm）；
5. 槽的**高端**压在垫块上，低端搭在摇臂末端 —— 坡度应该正好是 15°；
6. 内壁用 800 目砂纸打磨 + 少量滑石粉。

### 5.3 逐个验证

```
d 30   → 斜导流槽出口应正对红盒盒心
d 65   → 黄盒
d 100  → 绿盒
d 135  → 蓝盒
d 170  → 橙盒
```

**都偏了同一个角度** → 改 `config.h` 的 `SORTER_TRIM_DEG`（例如都偏 +5°，就填 `-5`）。
**只有某一个偏** → 直接改 `kBinAngle[]` 里那一项。

### 5.4 落点试验（一定要做）

拿 10 颗糖豆，**一颗一颗**放进槽的高端，每个盒位试 2 颗：

| 现象 | 处理 |
|---|---|
| 糖豆停在槽里不走 | 加大坡度（15° → 18°），或把内壁打磨 + 滑石粉 |
| 糖豆滚太快、弹出盒外 | 减小坡度（15° → 12°），或降低槽口高度（15 → 10 mm）|
| 糖豆落在盒子边缘 | 微调该盒位的 `kBinAngle[]`，每次 ±3° |
| 糖豆卡在落料管和槽之间 | 落程（落料管下端到槽面 12 mm）太小，加大到 15 mm |

### 6.2 上电自检

**上电瞬间应该看到**：
- 板载 LED 常亮
- 挡板A、挡板B 都关到 0°

## 7. 阶段七：调光与颜色标定（关键步骤）

### 7.1 调光与阈值（先做这步）

1. 串口发 `t` 打开原始光谱流，会每 300 ms 打印一行：
   ```
   RAW F1..F8   120   118   115   110   108   105   102   100 | CLR   340 NIR   210 | hue= 210.0 sat=0.06 | (empty)
   ```
2. **关掉房间大灯**，再读一次。两次的 `CLR` 值如果差别很大，说明**遮光罩在漏光**，回 `04` 文档 §5.1 返工，别急着标定。
3. 记录**仓里没有糖豆**时的 `CLR` 值（例如 340）。
4. 把 `config.h` 的 `MIN_CLEAR_LEVEL` 设成它的 **1.5–2 倍**（例如 600）。
5. 手动放一颗糖豆到挡板B 上，再读一行：
   ```
   RAW F1..F8   180   210   260   420   690   980  1240   760 | CLR  1840 NIR   260 | hue=  12.3 sat=0.74 | RED
   ```
   `CLR` 应明显高于阈值（1840 > 600 ✓）。

**判断"饱和没饱和"**：如果 F1–F8 里任何一个接近 **65535**，说明积分时间或增益太大，把 `AS7341_GAIN` 从 `AS7341_GAIN_16X` 降到 `AS7341_GAIN_8X`，或者把 `AS7341_ATIME` 从 19 降到 9。

**高光太强怎么办**：如果糖豆表面有一块明显过曝的高光，先试把 `AS7341_LED_MA` 从 20 降到 10，再把模块多偏转几度。

### 7.2 标定流程

1. 串口发 `m` 进入手动模式（这样糖豆不会被放走）。
2. 挑 5 颗**颜色最标准**的糖豆（红、橙、黄、绿、蓝各一颗）。
3. 把红的那颗放到挡板B 上，输入：
   ```
   c 0
   ```
   应返回：
   ```
   CAL RED: hue=12.3 sat=0.74 Clear=1840 NIR=260
         spectrum F1..F8: 0.038 0.044 0.055 0.089 0.146 0.207 0.262 0.159
   send 's' to save to flash
   ```
   那 8 个小数就是这条**归一化光谱**，判色时就是拿它去比对。
4. 依次换成橙 `c 1`、黄 `c 2`、绿 `c 3`、蓝 `c 4`。
5. 全部完成后输入 `s` 保存到 Flash。
6. 输入 `x` 退出手动模式。

### 7.3 标定结果自检

输入 `p`，会打印状态、计数、以及 5 条参考光谱：

```
fw=3.0 state=1 total=0 unknown=0 jam=0 calibrated=1 raw=0 man=0 fault=0
  RED    0   (bin 30 deg)
  ORANGE 0   (bin 170 deg)
  YELLOW 0   (bin 65 deg)
  GREEN  0   (bin 100 deg)
  BLUE   0   (bin 135 deg)
  rocker now=0 home=0
  chamber WxDxH = 15x15x15 mm  (candy 13x13)
  reference spectra (F1..F8):
   RED    0.038 0.044 0.055 0.089 0.146 0.207 0.262 0.159
   ORANGE 0.041 0.048 0.058 0.092 0.152 0.244 0.232 0.133
   YELLOW 0.052 0.060 0.071 0.098 0.148 0.176 0.230 0.165
   GREEN  0.055 0.070 0.110 0.185 0.230 0.160 0.110 0.080
   BLUE   0.120 0.185 0.230 0.175 0.125 0.075 0.050 0.040
```

**怎么看这 5 行**：
- 每一行的 8 个数之和都是 1；
- **不同颜色的曲线形状必须明显不同** —— 比如红的 F7(630nm) 应该是整行里最大的，蓝的 F2/F3 最大；
- 如果红和橙两行几乎一样，说明**光谱分辨率没发挥出来**，检查是不是遮光罩漏光、或者 LED 太亮导致高光把曲线"洗白"了。

再逐颗放糖豆，打开 `t` 观察每颗判成什么色，以及 OLED 右下角显示的**距离值**（`CAL+ RED 0.0012` 这种）。

### 7.4 判色不准怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 总是 UNKNOWN，`t` 显示 `(empty)` | 亮度不足 | 检查 LED 是否亮；降低 `MIN_CLEAR_LEVEL`；加大 `AS7341_ATIME`（19 → 49）|
| 总是 UNKNOWN，`t` 显示 `(white/bg)` | 饱和度门限过高（只影响未标定兜底）| 把 `MIN_SATURATION` 从 0.25 降到 0.15；或者**直接标定**，标定后走光谱近邻，不用色相 |
| 标定后仍经常 UNKNOWN | `MAX_SPECTRAL_DIST` 太严 | 从 0.004 放宽到 0.008 |
| 红/橙偶尔互换 | 两者光谱太接近，或高光干扰 | 先把 LED 电流降到 10 mA、模块再偏转几度；仍不行就把 `MAX_SPECTRAL_DIST` 收到 0.002 并重新标定 |
| 同一颗糖多次测距离值忽大忽小 | 反光 / 模块没固定牢 | 固定模块；加黑色绒布内衬；`COLOR_SAMPLE_TIMES` 从 3 加到 5 |
| 换一批糖豆就全乱 | 批次色差 | **重新标定** |
| 开灯关灯读数差别很大 | 遮光罩漏光 | 用黑色热熔胶封堵所有缝隙；这是最常见也最容易忽略的问题 |
| 读数一直不动 / 全 0 | I2C 卡死或模块没供电 | 复位；查 `i2cMutex` 用法；量模块 VCC |

> **加重判据技巧**：如果红/橙还是分不开，可以在 `classifySpectrum()` 里加二次判据 —— 比如要求「最近邻距离 < 次近邻距离 × 0.7」才接受，否则判 UNKNOWN。宁可判 UNKNOWN 进废料槽，也不要判错进错盒。

## 8. 阶段八：节拍与动作调参

所有参数都在 `firmware/include/config.h`，改完重新编译烧录即可。

### 8.1 常见调参场景

| 症状 | 调整参数 | 方向 |
|---|---|---|
| 糖豆还没停稳就读光谱，判色乱 | `T_GATE_SETTLE`、`T_COLOR_SETTLE` | **调大**（各 +60 ms）|
| 挡板B 还没关好，下一颗就掉下来了 | `T_DROP_RECOVER` | **调大**（+80 ms）|
| 糖豆卡在挡板B 上没落下 | `T_DROP_HOLD`、`GATE_OPEN_ANGLE` | 时间调大 / 角度调大 |
| 底部摇臂还没转到位就放料 | `T_SORTER_MOVE` | **调大**（+100 ms）|
| 整机太慢（想更快）| 上表 4 个参数 + `AS7341_ATIME` | 逐项**调小**，每次 30 ms，直到临界再加 20 ms 余量 |
| 一次掉两颗糖豆 | 挡板A/B 净高 | 见 §4.2，**这是机械问题，不是参数问题** |
| 送料老是卡（`JAM`）| 糖豆盒漏斗出口、单列导管内径 | 加大漏斗出口 / 打磨内壁 / 开 `ENABLE_VIB_UPGRADE` |
| 落点偏一点 | `kBinAngle[]` | 微调对应角度 ±3° |
| 所有落点整体偏 | `SORTER_TRIM_DEG` | 反向补一个固定偏移 |
| 光谱波动大 | `COLOR_SAMPLE_TIMES`、`AS7341_ATIME` | 都**调大** |

### 8.2 推荐调参顺序

```text
1. 先调「闸门」   → 保证每次只掉一颗、且能停稳在 B 上
2. 再调「判色」   → 先封光，再调光（t 命令），最后标定
3. 再调「底部摇臂」→ 保证转到位再放料、落点准
4. 最后压时间     → 逐项减小延时，逼近临界
```

**别跳步**。一次只改一个参数，改完记一笔（建议用下节的记录表）。

## 10. 验收测试

### 10.1 准确率测试

1. 随机取 **100 颗**混合糖豆放入糖豆盒。
2. 跑完全程，记录每种颜色的**实际数量**（人工数）与**机器计数**（`p` 命令）。
3. 计算准确率：

```text
准确率 = (总计数 - 未知计数) / 总计数 × 100%
```

**✅ 验收标准**：
- 准确率 ≥ 95%
- 卡料次数 ≤ 2 次 / 100 颗
- **无漏分**（没有糖豆留在单列导管、导流槽里，或掉到地上）

### 10.2 速度测试

```text
分拣速度 = 100 颗 / 总耗时（分钟）
```

**✅ 验收标准**：≥ 25 颗/分钟（即 100 颗 ≤ 4 分钟）。

### 10.3 连续运行测试

连续跑 30 分钟，观察：
- 是否过热（舵机、电源、ESP32）
- 计数是否有漂移
- 是否出现 I2C 死锁（表现为 OLED 卡住 + 不再分拣）
- 闸板导轨和导流槽内是否有糖粉堆积（有的话擦干净，撒点滑石粉）
- **泡棉板有没有受潮变形**（泡棉板吸水后会软，导轨和闸门会失准；必要时换成双层瓦楞板或加铝型材）

## 11. 故障速查总表

| 症状 | 排查顺序 |
|---|---|
| 上电无反应 | 电源 → 开关 → ESP32 板载 LED → USB 供电 |
| 串口无输出 | 波特率是否 115200 → 换 USB 数据线 → 换串口芯片驱动 |
| 扫不到 0x39 | SDA/SCL 接反 → 模块 VIN 误接 5V → 换模块 |
| OLED 花屏 | I2C 速度 → 上拉电阻 → 换 0x3D 地址 |
| 舵机不动 | 信号线 GPIO → 独立 5V 供电 → 舵机本身好坏（拿另一个试）|
| **命令动了"错误的"舵机** | 信号线接错，对照 `03` 文档 §1.1 |
| 舵机抖动/复位 | 电源电流不足 → 加 1000 µF 电容 → 增大电源功率 |
| 挡板A 关不上 / 舵机吱吱叫 | A/B 净高太小 → 见 §4.2 |
| 一次掉两颗 | A/B 净高太大 → 见 §4.2 |
| 挡板B 关上后红外一直触发 | TCRT5000 灵敏度太高 / 仓内反光 → 调电位器 |
| 红外从不触发 | DO 未接 / 电位器太低 / 探头离糖豆太远 / 缺 10k 上拉 |
| OLED 右上角一直是 `FAULT` | 上电自检没过：先看串口是 `TCRT5000 DO reads LOW` 还是 `AS7341 not found`，再对应排线 |
| 判色全 UNKNOWN | LED 没亮 → 遮光罩漏光 → `MIN_CLEAR_LEVEL` / `MAX_SPECTRAL_DIST` → 重新标定 |
| 判色飘忽、重标定结果不稳定 | **遮光罩漏光** → 黑色热熔胶封堵所有缝隙；模块四周打胶固定 |
| 串口打印 `WATCHDOG: candy on gate B with no color result` | 判色结果丢了（队列满 / TaskColor 异常）。机器会按 UNKNOWN 自动放行一次，不用干预；频繁出现说明 I2C 不稳 |
| 串口打印 `candy still on gate B -> re-open` | 糖豆粘在闸板上。擦干净闸板、撒滑石粉；若一直清不掉会打印 `JAM: gate B did not clear` |
| 串口打印 `too many UNKNOWN in a row` | 遮光罩漏光 / 没标定 / LED 灭了。先 `t` 看光谱，再重新 `c` + `s` |
| 卡料（`JAM`）| 糖豆盒漏斗出口 → 单列导管内径 → 过渡锥角 → 开 `ENABLE_VIB_UPGRADE` |
| 糖豆停在斜导流槽里 | 坡度 15° → 18°；内壁打磨 + 滑石粉 |
| 糖豆弹出盒外 | 坡度减小；降低槽口高度；检查出口是否高于盒沿 10–20 mm |
| 整机停摆不动 | 是否打印 `JAM` → 复位重启 → 检查 `semNextCandy` 是否被吞（重启恢复）|
| 串口 `p` 里 `rocker now=` 与命令不符 | 底部舵机信号线松动 |

## 13. 安全与保养

- **断电再接插拔舵机**，带电插拔容易烧驱动。
- **首次上电前先把三个舵盘拆下来**，否则固件把挡板关到 0° 时可能顶死烧舵机。
- **泡棉板怕潮。** 长期不用时取出糖豆，整机放在干燥处；受潮变形后导轨会失准。
- 热熔胶枪温度别太高，**烫穿泡棉板就废了**；打胶要快、要少。
- 每运行 10 小时，清理一次单列导管、闸板、导流槽的糖粉。
- 泡棉板和热熔胶不适合长期接触食品，接触面可贴食品级 PTFE 胶带。
- 电源适配器要留散热空间，不要闷在密闭盒里。
