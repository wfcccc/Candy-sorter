# 04 · 机械结构图纸（v3 · 泡棉板 L 形骨架 + 单颗测色仓 + 摇臂斜导流槽）

> 本文用**切割清单 + 尺寸表 + 示意图**描述整机机械结构。
> **全部结构件都是 5 mm 泡棉板（或双层瓦楞板）手工切割**，用热熔胶 + M3 螺丝 + 扎带装配。
> 不需要 3D 打印机，不需要建模，买齐材料当天就能下刀。
> 本文所有尺寸均为**设计基准值**，首次装配请按实际糖豆直径微调（见 §8）。

## 3. 关键设计决策：糖豆在哪里判色？

这是本机最容易做错的一点，先讲清楚。

**图注原文：**
> 单颗测色仓：**A 和 B 之间就是检测仓；B 同时充当底板与放料门。**
> AS7341：模块固定在黑色遮光罩**外**，芯片与板载白光 LED 通过窗口朝向糖豆。

所以：**挡板A 是仓顶，挡板B 是仓底兼放料门，糖豆就停在 B 上被 A 和 B 夹在中间。**

工作循环：

```
① 挡板A 打开 → 一颗糖豆从单列导管落进货仓，砸在挡板B 上
② 挡板A 关闭 → 刀刃楔进第 1、2 颗糖豆的切点，把上面的整列闸住
③ 仓里只有一颗糖豆，A 和 B 把它夹住；AS7341 透过窗口读光谱
④ 底部摇臂先转到目标盒位
⑤ 挡板B 抽开 → 糖豆落下，穿过固定落料管，落到斜导流槽的高端
⑥ 糖豆靠重力沿槽滚下，从出口掉进对应方盒
⑦ 挡板B 关闭 → 回到 ①
```

**为什么仓腔要做得这么小？** 图注给的是「糖豆直径 + 2 mm」这种量级 —— 一个小到刚好装下一颗糖豆的黑腔，杂光几乎进不来，而且白光 LED 的光会在腔内多次反射，把糖豆照得很均匀。反过来，如果把仓做大（比如做成 50 mm 的盒子），壁面反光会变成大面积的杂散光，判色立刻变差。

**为什么传感器装在遮光罩外面？** AS7341 模块有 25 mm 见方，塞进 15 mm 的仓里是不可能的。让它贴着窗口朝里看，芯片和 LED 一起透过窗口照到糖豆上。

> ⚠️ **AS7341 的芯片和板载 LED 在同一个模块上、相距只有几毫米**，等于近似同轴照明，球面上的糖衣**一定**会有一块镜面高光反射进芯片。本方案靠三件事压制它：
> 1. 模块整体**偏转 15°–25°** 安装，让镜面反射方向偏离芯片；
> 2. 在 LED 那一小片区域贴一小块**白色哑光胶带/纸**做柔光；
> 3. 判色用的是**归一化光谱向量**（见 `01` 文档 §7），高光往所有通道里加的是近似等量的白光，归一化之后影响被大幅摊薄。
>
> 如果你的模块 LED 太亮导致高光明显，先用 `setLEDCurrent()` 把电流降到 10 mA 试试（`config.h → AS7341_LED_MA`）。

**遮光做法**（这是判色的第一前提）：

1. 遮光罩五块板全部用**哑光黑**（黑色卡纸 / 黑色自粘绒布 / 黑色泡棉板）；
2. 内壁贴一层黑色绒布 —— 绒布的漫反射比纸板低得多；
3. 闸板缝的外侧用一块黑色小板做**挡光檐**，别让光从缝里直射进来；
4. 观察窗周围打一圈热熔胶，模块压上去之后从侧面看**不能有缝**；
5. 装完做个验收：**把机器搬进小黑屋（或关灯），OLED/串口读到的 Clear 值应该接近 0**。如果开灯和关灯的 Clear 值差不多，说明漏光已经治好了。

> ⚠️ 图注给的三个尺寸是**净空**，不是板的外廓。上表的「30 × 30 × 40 遮光罩内腔」是外壳，仓腔 15×15×15 是靠 P16 那 4 条限位条在里面围出来的。

### 5.2 双闸门机构（本机的核心机构）

**原理：曲柄滑块。** 舵机轴竖直，摇臂对称摆动 ±32.5°，臂端的销钉走出约 21 mm 的近似直线行程，推动闸板沿导轨滑动。

```text
   挡板机构 俯视 (舵机在背板外侧, 闸板从遮光罩后板的缝里捅进去)

          关闭状态 (舵机 0°)                打开状态 (舵机 65°)

   ┌──────────────────────────┐      ┌──────────────────────────┐
   │ 仓内          │  座内      │      │ 仓内          │  座内      │
   │              │            │      │              │            │
   │      ┌───┐   │  ╭─摇臂    │      │      ┌───┐   │            │
   │      │ ● │   │ ╱  ●销     │      │      │ ● │   │      ╭─摇臂│
   │      └───┘   │●           │      │      └───┘   │       ●销  │
   │   ═══════════┤  (闸板在前)│      │         ═════┤  ╲         │
   │   闸板盖住通道 │            │      │  闸板退到后面  │   ╲        │
   └──────────────┴────────────┘      └──────────────┴────────────┘
        ↑ 糖豆被挡住                        ↑ 糖豆落到挡板B上
```

| 尺寸 | 数值 | 说明 |
|---|---|---|
| 闸板 | **38 × 22 × 1.5 mm**（硬卡纸 / 1.5 mm 亚克力 / 薄泡棉板）| 销钉装在距前缘 32 mm 处 |
| 闸板行程 | **21 mm** | 全闭时前缘越过通道 1.5 mm，全开时退出 2.5 mm |
| 摇臂 | **20 mm**（P8 上打的孔位）| 装在舵盘上 |
| 摇臂摆角 | **±32.5°**（舵机 0° ↔ 65°）| 销钉走 21.4 mm 直线，横向窜动仅 3.1 mm |
| 销 / 槽 | φ3 竹签销 + 沿闸板**宽度**方向 8 mm 的长圆槽 | 吸收那 3.1 mm 横向窜动 |
| 舵机安装角 | 舵机写 **32.5°** 时压装舵盘，摇臂指向**背离遮光罩**的方向 | 这样 0° = 全闭，65° = 全开 |
| 舵机固定 | 法兰落在背板外侧，M3 螺丝 + 扎带各一道 | 泡棉板吃不住螺丝，**扎带是主力** |

**装配顺序（关键）**

1. 先把两个 SG90 用扎带固定在背板外侧，**不要装舵盘**；
2. 串口发 `m` 进手动模式，再发 `a 0`（挡板A 转到 0°）—— 此时舵机在「全闭」位置；
3. 装上舵盘，让摇臂指向**背离遮光罩的方向**；
4. 装闸板，手动推拉确认能顺畅走完 21 mm，且全闭时前缘完全越过通道；
5. 发 `a 1` / `a 0` 反复验三次；
6. 挡板B 同样操作（`b 1` / `b 0`）。

**失效安全**：舵机断电时闸板会被糖豆柱推开（曲柄没有自锁）。这是**故意的**：万一断电，糖豆会一路滑到导流槽并落进最近的盒子，而不是把整列卡死在管里。

**为什么槽的高端要在轴心上？** 摇臂绕舵机轴旋转，槽的高端就在轴心（r≈0）。固定落料管对准轴心垂直落下 —— 于是**无论摇臂停在哪一个角度，糖豆都必定落到槽的高端**，不会掉到盒子外面。槽再从高端把糖豆送到目标盒子上方。

**装配顺序**

1. 舵机放进 90×90 盒里，法兰用 M3 螺丝 + 扎带固定在顶板上，轴朝上；
2. 串口发 `d 0`，把摇臂压到舵盘上，让槽的高端**正对 0° 基准线**（废料槽方向）；
3. 把 P9 三角垫块粘在摇臂上，再把 P10/P11 粘成 U 形槽，槽的高端压在垫块上、低端搭在摇臂末端；
4. 用角度尺量坡度，调到 15°（垫块高度就决定了坡度，改坡度就换垫块）；
5. 串口 `d 30` / `d 65` / … 逐个验证出口正对 5 个盒心。

## 7. 加工与装配要点

### 7.1 切泡棉板

| 要点 | 说明 |
|---|---|
| 刀要新 | 泡棉板是「切」不是「划」，刀片一钝就撕出毛边。切 20–30 刀换一次刀尖 |
| 用钢尺压住 | 每一刀都靠钢尺，手切的直边全靠它。别信自己的手 |
| 分层切 | 5 mm 板分 2–3 刀切透，一刀到底容易斜 |
| 切完修边 | 400 目砂纸把切面磨平，尤其是**导轨和闸板经过的地方** |
| 打孔 | 泡棉板不适合钻孔（会撕）。用**烧热的铁钉/竹签**烫孔，又快又光 |
| 连接 | 热熔胶为主。胶枪温度别太高，**烫穿泡棉板就废了**；打胶要快、要少 |
| 加固 | 直角处一定加 P4 三角撑；受力孔（舵机法兰）外面贴一块小泡棉板做垫片，再用扎带 |

### 7.2 装配顺序（照这个来，别跳）

1. **底板 + 背板 + 三角撑** → L 形骨架，检查直角；
2. **遮光罩 5 块板** → 粘成方筒，内壁贴黑绒布，前板留观察窗；
3. **遮光罩顶板/底板** → 烫 φ16 过料孔和 1.8 mm 闸板缝，外侧加挡光檐；
4. **仓腔限位条 P16** → 在筒内围出 15×15 的通道；
5. **两个闸门舵机 + 摇臂 + 闸板** → 按 §5.2 的顺序装，装完手动验行程；
6. **AS7341 模块** → 贴在前板外侧，偏转 15°–25°，周围打胶封光；
7. **底板舵机台盒 + 舵机 + 摇臂 + 斜导流槽** → 按 §5.3 的顺序装；
8. **固定落料管** → 从遮光罩底板通到摇臂轴心上方，垂直；
9. **单列导管 + 糖豆盒 + 上层板** → 管子必须**垂直**，歪 3° 就会卡豆；
10. **5 个方盒 + 废料槽** → 按 §6 的刻度摆位。

### 7.3 无泡棉板时的替代

| 零件 | 替代做法 |

| 三角垫块 | 叠几层泡棉板边角料削成楔形；或一截斜切的竹筷 |

## 9. 装好后必须手验的 8 件事

1. 放一颗糖豆在单列导管里，手动开合挡板A 三次 —— **每次只能掉下一颗**到挡板B 上；
2. 糖豆停在挡板B 上时，**把整机搬进暗处，串口 `t` 读到的 Clear 值应该接近 0**（漏光就返工遮光罩）；
3. 舱里放一颗糖豆，`t` 读数应该稳定；同色糖豆连测 5 次，各通道波动应小于 5%；
4. 给舵机写 0°，斜导流槽高端应正对 0° 刻度线；逐个写到 30/65/100/135/170°，出口应正对 5 个盒心；
5. 在槽的高端放一颗糖豆，转到任一角度，糖豆应能顺畅滚进对应盒子，**不卡在槽里、不弹出盒外**；
6. 手动让摇臂转满 0→180→0，全程**不碰盒沿、不碰背板、不碰废料槽**；
7. 断电再上电，三个舵机应回到「A 闭、B 闭、底部 0°」的初始姿态；
8. 连倒 20 颗糖豆跑一遍，观察有没有卡料、有没有两颗同时掉。
